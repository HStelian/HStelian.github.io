# Portofoliu personal

Acest site prezintă proiecte personale din mai multe domenii. Fiecare proiect are un stadiu clar și poate include descriere, demo, capturi de ecran, aplicații descărcabile și alte materiale.

Domeniile se stabilesc în funcție de proiectele adăugate. Cardurile proiectelor care au activată pagina de detalii deschid o prezentare separată cu informațiile și materialele disponibile.

Proiectele pot fi în faza de idee, experiment, testare sau lucru. Stadiul afișat indică ce a fost realizat până acum.
