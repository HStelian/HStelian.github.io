Editează proiectele

Adaugă proiecte din orice domeniu. Domeniul este liber, iar paginile detaliate pot fi activate separat pentru fiecare proiect.

Materialele proiectului
  1. Fiecare proiect are un folder sugerat în media/domeniu/proiect/.
  2. Încarcă acolo poze, capturi și fișiere de aplicații, apoi adaugă căile lor în câmpurile proiectului.
  3. Demo-ul web, repository-ul și pagina detaliată sunt opționale.

Se încearcă încărcarea automată a projects.json…

Fișierele mari pot fi găzduite separat, de exemplu într-o versiune GitHub Releases. După editare, descarcă și publică noul projects.json.
