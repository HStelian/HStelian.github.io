# CV-uri

Încarcă în acest folder cele două fișiere Word, cu numele exacte:

- `CV_Hudea_Stelian_RO.docx` — CV în română
- `CV_Hudea_Stelian_EN.docx` — CV în engleză

Pagina `cv.html` verifică automat dacă documentele există și afișează butoanele de descărcare. Până la încărcare, fiecare card afișează „Documentul nu este adăugat încă.”.

Pentru actualizare, înlocuiește documentul păstrând numele. Nu trebuie modificat codul. Modificările devin vizibile după publicarea GitHub Pages.
